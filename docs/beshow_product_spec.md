# 비었쇼(Be:show) 제품 정의서

## 1. 제품 개요

## 1.1 제품 정의
- 비었쇼는 매대 이미지를 분석해 진열 상태를 점검하고, 창고 재고와 결합해 직원에게 `보충 필요/확인 필요/발주 필요`를 안내하는 매대 운영 보조 시스템이다.

## 1.2 핵심 문제
- 현장은 `매대 확인 -> 재고 확인 -> 보충/발주 판단`을 수작업으로 반복해 비효율이 크다.

## 1.3 핵심 해결
- CV 기반 진열 상태 감지와 재고 연동으로 작업 리스트 중심 운영을 제공한다.

---

## 2. 목표와 KPI

## 2.1 제품 목표
1. 지금 처리해야 할 SKU를 즉시 제시한다.
2. 보충/발주 판단 시간을 줄인다.
3. 오진열/저신뢰 항목을 분리해 점검 효율을 높인다.

## 2.2 MVP KPI
1. 보충 필요 판정 정확도
2. 발주 필요 판정 정확도
3. 작업 준비 시간 단축률
4. 보충/발주 누락 건수 감소율

---

## 3. 사용자
1. 점포 직원(알바/점장)
2. 점포 운영 관리자

---

## 4. MVP 범위

## 4.1 대상
1. 상온 선반 핵심 SKU
2. 카테고리: 과자/면류/통조림_안주/상온식품/기타
3. 운영 선반: 선반 A, 선반 B

## 4.2 입력
1. 고정 카메라 매대 이미지
2. SKU-slot 매핑
3. 창고 재고(수량, ROP)

## 4.3 출력
1. 상태: `정상/보충 필요/확인 필요/발주 필요`
2. SKU별 작업 리스트
3. 위치/탐지시각/confidence
4. 알림 이벤트

## 4.4 화면 범위
1. `SCR-1` 보충 필요 리스트
2. `SCR-2` 발주 필요 리스트
3. `SCR-opt` 알림 패널

---

## 5. 운영 정책
1. `보충 필요 + 발주 필요` 동시 성립 SKU는 SCR-2 우선 노출
2. 리스트는 한 SKU당 한 행 원칙
3. 알림은 우상단 벨 아이콘 기반 슬라이드 패널로 제공

---

## 6. 제외 범위(Phase-2)
1. 자동 발주 생성
2. 수요예측 기반 최적 발주
3. 멀티점포 통합 최적화
4. 고급 설정 화면(SCR-05)
